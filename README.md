# Домашнее задание к работе 3: Расчет сопротивления резисторов

## Условие задачи
>Написать и отладить программу расчета сопротивления двух последовательно и
> параллельно соединенных резисторов (сопротивления резисторов задается пользователем).

## 1. Алгоритм и блок-схема

### Алгоритм
1.  **Начало**
2.  **Ввод данных:**
    *   Запросить у пользователя сопротивление первого резистора (`r1`).
    *   Запросить у пользователя сопротивление второго резистора (`r2`).
3.  **Вычисления:**
    *   Рассчитать сопротивление при последовательном соединении: `r_pos = r1 + r2`.
    *   Рассчитать сопротивление при параллельном соединении: `r_par = (r1 * r2) / (r1 + r2)`.
4.  **Вывод результатов:**
    *   Вывести на экран значения `r_pos` и `r_par`.
5.  **Конец**

## 2. Реализация программы

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

int main()
{
    setlocale(LC_ALL, "RUS");

    double r1, r2;
    double r_pos, r_par;

    printf("Введите сопротивление 1-го резистора: ");
    scanf("%lf", &r1);
    printf("Введите сопротивление 2-го резистора: ");
    scanf("%lf", &r2);

    r_pos = r1 + r2;
    r_par = (r1 * r2) / (r1 + r2);

    printf("Сопротивление при последовательном соединении: %.2f Ом\n", r_pos);
    printf("Сопротивление при параллельном соединении: %.2f Ом\n", r_par);

    return 0;
}
```
